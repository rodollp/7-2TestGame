# 게임 가제 : 무림초출


# 대표 사용자 페르소나

## 1. 대표 사용자

- 이름: 철수
- 나이: 26세
- 플랫폼: PC
- 하루 플레이 시간: 1~2시간
- 좋아하는 게임: 로그라이크, 로그라이트, RPG
- 게임에서 기대하는 것: 다양한 빌드 연구와 성장의 재미
- 싫어하는 것 : 정답 빌드만 존재하는 게임과 반복적인 플레이

---

## 2. 사용자 목표

플레이어는 자신만의 무공 조합과 문파를 만들어가며 매 플레이마다 새로운 전투 방식과 숨겨진 이벤트를 경험하는 것을 목표로 한다.

---

## 3. 수익 모델

### 선택한 수익 모델

- 기본 유료 게임
- DLC 콘텐츠

### 선택 이유

완성도 높은 본편을 제공한 뒤 신규 문파, 신규 지역, 신규 무공 등을 DLC 형태로 지속 확장하기 위함

### 사용자가 부담스럽게 느낄 수 있는 점

- 무협 세계관에 익숙하지 않은 유저는 접근이 어려울 수 있음

### 해결 방법

- 무협 용어를 쉽게 설명
- 문파 시스템을 직관적인 빌드 시스템으로 설계
- 무협을 몰라도 판타지 게임처럼 자연스럽게 즐길 수 있도록 구성

---

## 4. 한 문장 정리

> **무림초출은 플레이어의 선택으로 자신만의 문파와 무공 빌드를 만들어가는 3D 무협 액션 로그라이트로, 매 플레이마다 새로운 전투 스타일과 이야기를 경험하는 재미를 제공하는 게임이다.**
