# 카드 사용 시스템

## 개요

플레이어가 카드를 선택하면 시스템은 사용 가능 여부를 검사한 뒤,
효과를 적용하고 후처리를 수행한다.

---

## 시스템 흐름도

![카드 사용 시스템](Images/CardUseSystem.png)

---

## 시작 조건

- 플레이어의 턴이다.
- 플레이어가 손패의 카드를 선택했다.

## 입력

- 선택한 카드
- 현재 에너지
- 선택 대상
- 상태이상
- 카드 사용 제한 조건

## 처리 과정

1. 카드 선택
2. 카드 사용 조건 확인
3. 대상 확인
4. 카드 효과 적용
5. 카드 후처리
6. 결과 출력

## 조건 분기

### 사용 가능한가?

- 예 → 카드 효과 적용
- 아니오 → 사용 불가 처리

### 대상 지정 카드인가?

- 예 → 대상 선택
- 아니오 → 즉시 효과 적용

## 예외 상황

- 에너지 부족
- 대상 없음
- 카드 사용 불가 상태
- 이미 사망한 대상 선택

## 출력

- 피해량
- 방어도
- 상태이상
- 남은 에너지
- 카드 이동 결과

## 관련 클래스

- BattleManager
- TurnManager
- CardManager
- HandManager
- DeckManager
- EnergyManager
- EffectResolver
