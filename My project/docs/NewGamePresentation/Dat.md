게임 가제:

1. 플레이어가 가장 자주 하는 행동
-  카드를 선택하여 공격 또는 방어 
-  선택지 중 하나를 골라서 카드 선택

2. 그 행동이 필요한 이유
-  유저의 선택으로 인하여 빌드 완성
-  적들을 처지하고 게임 클리어가 목적


3. 행동을 시작하는 입력
- 마우스를 드래그하여 적을 선택
- 마우스 포인트가 적용될 대상을 고르고 단축키를 사용하여 적용

4. 행동 후 나타나는 출력
- 카드의 효과 발동
- 플레이어의 에너지 감소
- 디버프 적용

5. 성공 조건
- 카드 사용에 필요한 에너지
- 전제 조건
- 적용 대상이 있어야 발동

6. 실패 조건
- 에너지 부족
- 전제 조건을 만족시키지 못할시

7. 이 행동이 재미로 이어지는 이유
- 선택에 따라 달라지는 결과로 인하여 조합과 전략적 재미

8. 없어도 되는 기능
-  복잡한 이벤트
-  1인칭 시점
-  노가다를 통한 성장시스템
-  복잡한 전투방식

## 시스템 이름: 카드 사용 시스템

### 1. 시작 조건

* 플레이어의 턴에 손패의 카드를 선택했을 때

### 2. 입력 정보

* 선택한 카드
* 카드의 에너지 비용
* 플레이어의 현재 에너지
* 선택한 대상
* 플레이어와 대상의 상태이상
* 카드의 대상 지정 방식

### 3. 기본 흐름

1. 플레이어가 손패에서 카드를 선택한다.
2. 시스템이 현재 에너지와 카드 사용 조건을 확인한다.
3. 대상 지정이 필요한 카드라면 플레이어가 대상을 선택한다.
4. 카드의 효과를 적용한다.
5. 카드 비용만큼 에너지를 차감한다.
6. 사용한 카드를 버린 카드 더미로 이동한다.

### 4. 조건 분기

* 조건 A: 현재 에너지가 카드 비용 이상이다.

* 결과 A: 카드 사용을 진행한다.

* 조건 B: 현재 에너지가 카드 비용보다 적다.

* 결과 B: 카드를 사용할 수 없으며 효과가 발동하지 않는다.

* 조건 C: 공격 카드의 대상이 정상적으로 선택되었다.

* 결과 C: 선택한 적에게 카드 효과를 적용한다.

* 조건 D: 대상이 필요하지 않은 카드이다.

* 결과 D: 플레이어 자신 또는 전체 대상에게 카드 효과를 적용한다.

### 5. 예외 상황

* 예외 1: 공격 카드의 대상이 선택되지 않았다.

* 처리: 카드 사용을 진행하지 않고 대상 선택을 요구한다.

* 예외 2: 선택한 적이 이미 쓰러졌다.

* 처리: 해당 대상을 선택할 수 없게 하고 다른 대상을 선택하게 한다.

* 예외 3: 상태이상으로 인해 카드를 사용할 수 없다.

* 처리: 카드 사용을 취소하고 사용 불가 이유를 표시한다.

### 6. 종료 조건

* 카드 효과 적용, 에너지 차감, 카드 후처리가 모두 완료되었을 때
* 또는 카드 사용 조건을 만족하지 못해 사용이 취소되었을 때

### 7. 플레이어에게 보여줄 결과

* 카드 사용 애니메이션과 효과
* 소모된 에너지
* 적이 받은 피해 또는 상태이상
* 플레이어가 얻은 방어도 또는 강화 효과
* 카드가 버린 카드 더미로 이동한 결과
* 카드를 사용할 수 없을 경우 그 이유
