# 게임 가제

(미정)

## 1. 플레이어

- 플레이어의 역할:
  - 카드를 사용하여 적을 처치하고 덱을 성장시킨다.
- 플레이어가 조작하거나 선택하는 것:
  - 카드 사용
  - 턴 종료
  - 카드 보상 선택

---

## 2. 목표

- 단기 목표:
  - 현재 전투에서 승리한다.
- 장기 목표:
  - 최종 보스를 처치하여 게임을 클리어한다.

---

## 3. 절차

- 반복 플레이 순서:
  1. 전투 시작
  2. 카드 드로우
  3. 플레이어 턴
  4. 적 턴
  5. 전투 종료
  6. 카드 보상 선택
  7. 다음 전투 진행

---

## 4. 규칙

- 반드시 지켜야 하는 규칙:
  - 플레이어 턴에만 카드를 사용할 수 있다.
  - 카드 사용에는 에너지가 필요하다.
  - 턴 종료 후 적이 행동한다.

- 금지되는 행동:
  - 에너지가 부족한 카드를 사용할 수 없다.
  - 손패에 없는 카드를 사용할 수 없다.

---

## 5. 자원

- 얻는 자원:
  - 새로운 카드

- 쓰는 자원:
  - 에너지
  - 체력

- 부족하면 생기는 문제:
  - 에너지 부족 → 카드 사용 불가
  - 체력 부족 → 게임 오버

---

## 6. 챌린지

- 어려움이 생기는 지점:
  - 적의 행동 패턴
  - 덱 구성 실패

- 플레이어가 극복하는 방법:
  - 카드 조합 개선
  - 적 행동 예측
  - 덱 구성 최적화

---

## 7. 공식이나 테이블이 필요해 보이는 요소

- 카드 효과 데이터
- 카드 드로우 규칙
- 덱 / 손패 / 버린 더미 관리 규칙
- 에너지 회복 규칙
- 적 능력치 테이블
- 적 행동 패턴 테이블
- 전투 보상(카드) 선택 테이블
